# TAgentNote 前端周报与下一阶段规划

## 一、本周工作总结

### 1. 论文辅助模式从“切换文案”推进到“任务卡 + 分步写作”

- 论文辅助与课程答疑保留独立入口。
- 论文任务卡支持填写论文题目、关键词，并显示当前章节。
- 当前章节分为：选题与大纲、摘要、相关工作、研究方法、实验设计、结果与讨论、完整性检查。
- 根据当前章节动态显示对应的写作内容输入项和操作卡片，避免所有操作混在一起。
- 对用户展示“已选择论文任务卡：生成大纲”等简短信息，不再把内部系统提示词直接展示给用户。
- 论文任务卡展开后支持独立滚动，避免遮挡生成结果和输入框。

### 2. 论文写作输入更加具体

- 已为各类论文输入项增加“从笔记本选择笔记”能力，例如研究对象、研究问题、方法概述、数据来源、结果情况等。
- 已增加本地 CSV、TSV、TXT、Markdown、JSON、Excel 文件选择入口。
- CSV/Excel 等文件可以在前端读取并提取部分内容，作为当前论文任务的上下文预览。
- 已增加已选择笔记和已上传文件的展示与移除操作。

> 当前本地文件主要作为前端任务上下文使用，还没有完整接入 OpenNoteBook 的来源上传、解析和持久化流程。

### 3. 论文写作操作与课程论文流程对齐

- “生成大纲”对应选题与大纲章节。
- “起草摘要”对应摘要章节。
- “梳理相关工作”对应相关工作章节。
- “写研究方法”对应实体、事件、资源、系统边界和建模假设。
- “设计实验”对应场景、指标、参数和对照组。
- “完整性检查”用于检查缺少的摘要、假设、评价指标、参考文献和实验数据。
- “继续回答”已在论文模式下特化为“继续写当前章节”。

### 4. 论文模式与课程答疑模式完成会话隔离

- 论文辅助历史只显示论文会话。
- 课程答疑历史只显示课程答疑会话。
- 切换模式时进入另一套独立会话空间，不会把论文内容带到课程答疑中。
- 侧栏、搜索、归档列表也按照当前模式过滤。
- 没有模式标记的历史数据按课程答疑处理，兼容旧数据。

### 5. 交互和稳定性修复

- 修复新对话空态崩溃问题。
- 修复论文生成内容被任务卡遮挡的问题。
- 保留编辑、复制、朗读、点赞/点踩、继续写作、重新生成、加入笔记本等消息操作。
- 论文任务、章节、笔记选择和本地文件信息会随会话保存。

## 二、下一步前端工作方向

本周已经完成了“论文模式有入口、有章节、有写作卡片”。下一步只保留三个能够明显提升产品价值的方向：让学生更好地组织章节、让生成内容有证据、让论文能够被检查和追问。

### 1. 做“章节工作台”，减少聊天式写作的迷失感

将论文页面从单一聊天流升级成围绕当前章节的工作区：

- 左侧：章节列表、当前章节和章节完成状态。
- 中间：当前章节草稿，可编辑、保存版本、继续写本章。
- 右侧：引用资料、数据摘要和本章节写作要求。

聊天仍然保留，但主要承担解释、提问和生成局部内容的作用；章节草稿不再埋在消息流里。学生打开某一章节后，可以清楚看到“这一章写了什么、还缺什么、依据是什么”。

### 2. 做“证据链写作”，让引用成为正文的一部分

将当前的“选择笔记”升级为可视化证据链：

- 每个章节显示已绑定的笔记和数据文件。
- 每个生成段落旁显示引用标记或“暂无依据”标记。
- 点击引用标记可以查看具体笔记片段、文件列名或数据摘要。
- 显示章节的“证据覆盖率”，提醒学生哪些内容有教材支持、哪些内容需要自己补充。
- 允许把一条资料绑定到某个章节或段落，形成“资料 → 章节 → 段落”的关系。

这样论文辅助的核心价值就从“帮我写一段话”变成“帮我写出有依据的一段话”。

### 3. 做“论文质检 + 答辩预演”

完整性检查不只提示“缺少摘要”，还生成可以直接回答的问题：

- 你的研究问题是否能被实验指标回答？
- 模型假设是否有数据或教材依据？
- 基准方案和改进方案是否可比较？
- 结果是否包含重复次数或置信区间？
- 结论是否超出了实验数据能够支持的范围？

在此基础上增加“答辩预演”：系统根据论文当前内容提出问题，学生回答后，系统标记回答中仍然缺少的证据或需要修改的章节。

这样论文辅助会从写作工具进一步变成课程学习工具，帮助学生理解自己的论文，而不是只生成一份看起来完整的文本。

## 三、下一阶段建议交付的三个成果

### 1. 章节工作台原型

- 能从章节列表进入某一章。
- 能查看和编辑当前章节草稿。
- 能保存草稿版本并继续写当前章节。
- 能在侧边区域查看本章写作要求和已绑定资料。

### 2. 证据链侧栏

- 能查看当前章节绑定的笔记和数据文件。
- 生成内容可以显示引用标记和暂无依据标记。
- 点击引用后可以查看对应资料片段。
- 显示当前章节的证据覆盖情况。

### 3. 论文质检与答辩预演

- 完整性检查生成结构化问题清单。
- 学生可以逐项回答或补充资料。
- 系统根据回答标记缺失证据和需要修改的章节。
- 最终形成“待补充信息”和“答辩问题”两份清单。

## 四、下一阶段的产品判断标准

- 学生不需要在长对话中寻找某一章的内容，打开章节工作台即可继续写作。
- 每个关键段落都能看到依据、引用或“暂无依据”提示。
- 完整性检查能够指出具体问题，而不是只显示笼统的缺失项。
- 答辩预演能够暴露论文中的证据缺口和逻辑问题。
- 论文辅助的核心体验从“生成内容”转变为“组织、论证和检查内容”。
