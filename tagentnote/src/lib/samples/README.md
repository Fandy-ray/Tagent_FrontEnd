# 范例正文

把要在论文批改页里当范例用的文章放在这个目录，一篇一个 `.txt` 文件，UTF-8 编码。
`/essay` 的稿纸上方会按文件名顺序列出来，点一下就填进稿纸。

## 格式

第一行写题目，空一行，之后是正文：

```
排队论模型在银行窗口设置中的应用

排队论是研究随机服务系统的数学理论……
以银行网点为例……
```

没有空行就整篇当正文，题目取文件名。段落之间**不要**留空行——一行就是一段，
这和后端切段的规则一致（`app/util/text.py` 的 `split_sentences`）。

正文长度按去掉空白后的字数算，要在 100~6000 字之间，超出范围交不上去。

想控制出现顺序就给文件名加序号：`01-排队论.txt`、`02-数字孪生.txt`。

## 这些 .txt 不进仓库

`.gitignore` 里忽略了本目录的 `*.txt`。范例多半是从期刊、教材或同学作业里摘来的，
版权不在我们手上，**不要**把它们提交上去；换台机器重新放一份即可。
