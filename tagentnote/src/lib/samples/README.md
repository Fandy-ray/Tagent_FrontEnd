# 范例正文

答疑「论文助手」里的「填入范例」从这个目录取文章：一篇一个 `.txt` 文件，UTF-8 编码，
按文件名顺序轮流填进输入框，再点「交稿批改」就能演示批改。

## 格式

第一行写题目，空一行，之后是正文：

```
排队论模型在银行窗口设置中的应用

排队论是研究随机服务系统的数学理论……
以银行网点为例……
```

没有空行就整篇当正文，题目取文件名。段落之间**不要**留空行——一行就是一段，
这和后端切段的规则一致（`app/util/text.py` 的 `split_sentences`）。

正文长度按去掉空白后的字数算，要在 100~6000 字之间，超出范围交不上去。

想控制出现顺序就给文件名加序号：`01-排队论.txt`、`02-数字孪生.txt`。

## 哪些能提交

仓库是**公开**的，提交上去就等于公开转载。

- **自己写的、同学同意公开的**：直接命名成 `xx.txt`，提交上去，大家拉代码就有。
- **期刊、教材、别人的文章**（哪怕只是摘录）：命名成 `xx.local.txt`。`.gitignore` 忽略了
  `*.local.txt`，它只在你自己机器上出现在「填入范例」里，不会被提交。

范例会在构建时打进答疑页的代码里，每篇都会让页面变大一点，几篇就够，不必多放。
