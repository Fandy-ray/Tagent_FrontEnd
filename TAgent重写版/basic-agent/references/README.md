# 参考文献

出题、答疑、论文批改检索材料时，除了教材 `book1.md`，还会用到这个目录里的论文
（目前是《系统仿真学报》上和课程最相关的 14 篇，篇目见 `manifest.json`）。

## 全文不进仓库

仓库是公开的，期刊论文版权在期刊（官网写的是「版权所有 © 北京仿真中心 中国仿真学会」），
不能转载。所以仓库里**只有篇目清单**，全文在每个人自己的电脑上：

- **一键启动会自动下载**：`start.sh` / `start.ps1` 启动 basic-agent 之前运行
  `tools/fetch_references.py`，从期刊官网把还没有的论文下载到这个目录，并把 PDF 里的文字抽成同名 `.md`。
  已经有的直接跳过，所以只有第一次要等（14 篇约 23MB，4 篇并发约半分钟）。连不上期刊官网时十秒内放弃、照常启动，下次启动再补。
- 也可以手动运行：`uv run python tools/fetch_references.py`（在 basic-agent 目录下）。
- 这个目录里除了 `README.md` 和 `manifest.json`，其他文件都被 `.gitignore` 忽略。

## 加论文

- **期刊上的**：在 `manifest.json` 里照格式加一项（`key` 用英文和连字符，`pdf` 是官网「PDF」按钮的地址），
  下次启动自动下载。这一项会进仓库，别人拉代码后启动也会下到。
- **手头的 PDF / 文字稿**：直接把 `.pdf`、`.md` 或 `.txt` 放进来。PDF 会在下次启动时抽成 `.md`；
  `.md` 第一行写 `# 题目`、第二段写 `> 来源：……` 会被当成题目和出处，没写就用文件名。只在你自己电脑上生效。

加了或改了论文，下次启动时只给新内容算向量（加一篇不到 1 秒），没变的内容直接复用。
