# 前端配置与聊天切换

## 配置入口

组件位于 `src/lib/components/chat/Settings/Connections/AgentUserModels.svelte`，由原 `Connections.svelte` 引入。没有增加独立导航或登录体系。

表单字段包括配置名称、Base URL、上游模型、Bearer/None、API Key、Temperature 和启用状态。编辑时 Key 为空表示保留；完整 Key 从不回显。

## API 封装

`src/lib/apis/agent-user-model-providers/index.ts` 提供 list/create/update/delete/default 方法，全部携带当前登录 token，只访问同源 WebUI API。

## 模型刷新

保存、启用、禁用、删除或设置默认后，组件调用 `getModels(..., refresh=true)` 更新全局 `models` store。私有模型元数据带 `Personal` tag，原生 ModelSelector 负责展示和选择。

## 修改 UI 时的约束

继续复用现有 `Switch`、`ConfirmDialog`、`Tooltip`、`SensitiveInput` 和图标；保持设置页信息密度、圆角、颜色与移动端断点一致。改动后必须运行 `npm run check` 和生产构建。
