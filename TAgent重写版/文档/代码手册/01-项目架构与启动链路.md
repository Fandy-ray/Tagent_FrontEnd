# 项目架构与启动链路

## 目录职责

- `basic-agent/`：Flask 智能体服务、RAG、OpenAI-compatible 路由、全局 provider 注册表。
- `open-webui/`：SvelteKit 前端与 FastAPI 后端，负责账号、用户私有配置和同源代理。
- `scripts/`：启动与停止脚本（`start.ps1` / `stop.ps1` / `start.sh` / `stop.sh`）。
- `deploy/systemd/`：Linux 生产环境服务模板。
- `日志/`：开发变更与测试方法。
- `文档/`：汇报材料和代码手册。

## 启动顺序

启动与初始化合并为一条命令（`start.bat` / `scripts/start.ps1` / `scripts/start.sh`），脚本按以下顺序执行：

1. 检查 uv、Node.js（`>=18.13` 且 `<=22.x`）、npm，以及 `5000`、`8080` 端口是否空闲。
2. 按锁文件安装依赖：`basic-agent/uv.lock`、`open-webui/uv.lock`、`package-lock.json`。
3. 生成 `.env.runtime`（WebUI 会话密钥、Fernet 密钥、成对的内部 token）；已存在则保留不覆盖。
4. 启动 basic-agent，轮询 `http://127.0.0.1:5000/health`（最长 300 秒，首次需构建向量索引）。
5. 健康后启动 Open WebUI，轮询 `http://127.0.0.1:8080/health`。
6. Open WebUI 启动时执行 Alembic，数据库固定为 `open-webui/data/webui.db`。

PID 写入 `.run/`，运行日志写入 `logs/runtime/`，两者均被 `.gitignore` 排除。

> 注意两点：
> 1. 后端依赖必须按 `open-webui/uv.lock` 安装。`backend/requirements.txt` 只钉了直接依赖，未约束传递依赖，在 Python 3.12 上会把 `numba` 回溯解析到 `0.53.1`（仅支持 `<3.10`）导致源码编译失败。
> 2. 安装时使用 `uv sync --no-install-project`（配合 `UV_PROJECT_ENVIRONMENT=backend/.venv`）。若不加该参数，uv 会打包 open-webui 自身，触发 `pyproject.toml` 中的 hatchling 钩子执行 `npm install --force` 与 `npm run build`。

## 端口

| 端口 | 服务 | 暴露范围 |
|---:|---|---|
| 5000 | basic-agent | 固定 127.0.0.1 |
| 8080 | Open WebUI | 默认 127.0.0.1，`-Lan` / `--lan` 时为 0.0.0.0 |

## 停止

Windows 使用 `scripts/stop.ps1`（或双击 `stop.bat`），Linux 使用 `scripts/stop.sh`。脚本读取 `.run/` 下的 PID 文件，并校验该进程确实属于本项目后才终止，只终止本项目启动并验证通过的进程。不要按端口批量结束其他进程。
