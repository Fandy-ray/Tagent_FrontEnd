# 测试、调试与二次开发

## 常用命令

```powershell
cd <项目目录>
.\scripts\start.ps1              # 首次运行会自动完成初始化
.\scripts\start.ps1 -SkipBuild   # 前端未改动时跳过构建，加快重启
.\scripts\stop.ps1
```

basic-agent：

```powershell
cd basic-agent
.\.venv\Scripts\python.exe -m pytest -p no:cacheprovider -q
```

WebUI TAgent 测试应按目录分组运行，避免上游同名测试模块与 PostgreSQL 集成测试的收集约束：

```powershell
cd open-webui\backend
.\.venv\Scripts\python.exe -m pytest --import-mode=importlib -q open_webui\test\apps\webui\routers\test_agent_proxy.py open_webui\test\apps\webui\routers\test_agent_user_model_providers.py
.\.venv\Scripts\python.exe -m pytest --import-mode=importlib -q open_webui\test\models open_webui\test\utils
```

前端：

```powershell
cd open-webui
npm run check
npm run build
```

## 调试顺序

1. 健康接口不通：检查 `logs/runtime/basic-agent.err.log` 与 `logs/runtime/webui.err.log`。
2. 模型不出现：检查 provider 是否 enabled、默认引用、`/api/models`。
3. 私有模型 404：检查当前用户所有权和模型 ID。
4. `provider_url_blocked`：检查 HTTPS、DNS 解析与管理员 allowlist。
5. `provider_key_unavailable`：检查 Fernet 密钥是否与数据库密文一致。
6. 上游 401/429/504：分别处理 Key、额度/限流与超时。

## 二次开发入口

- 新业务接口：在 basic-agent 新 Blueprint 中接收 provider，不创建厂商专属客户端。
- 新配置字段：同时修改 Alembic、SQLAlchemy、Pydantic、公开响应、前端类型和迁移测试。
- 新模型协议：先判断是否仍是 Chat Completions；Azure、Responses、图像/音频应作为独立能力设计。
