# 模型注册表与动态路由

## 全局注册表

`basic-agent/model_config.py` 管理 schema v2：

```json
{
  "version": 2,
  "default_model_id": "simulation-teacher",
  "providers": []
}
```

每个 provider 包含 `name`、`served_model_id`、`base_url`、`upstream_model`、`auth_mode`、`api_key`、`temperature`、`enabled` 和时间戳。磁盘写入使用进程内锁、唯一临时文件、`flush + fsync + os.replace`。

## 路由规则

1. 请求显式提供 `model` 时查找同名启用 provider。
2. 未提供时使用 `default_model_id`。
3. 不存在或禁用返回 `model_not_found`。
4. provider 改动通过 `updated_at` 触发新客户端，并主动失效旧缓存。

## 用户私有模型

私有模型不进入全局 JSON。WebUI 将数据库记录解密为临时 provider envelope，basic-agent 的 `parse_ephemeral_provider()` 验证后直接使用。其稳定 `updated_at` 保证请求间客户端可复用。

## 增加新兼容模型

只需配置：

- Base URL 指向标准 OpenAI Chat Completions 服务。
- 上游模型填写服务实际模型名。
- Bearer 模式填写 Key；本地无鉴权服务选择 None。
- 不要为厂商增加专属 `if/else`，除非其协议并不兼容本轮接口。
