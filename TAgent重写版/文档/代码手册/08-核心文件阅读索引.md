# 核心文件阅读索引

| 顺序 | 文件 | 重点 |
|---:|---|---|
| 1 | `scripts/start.ps1` | 初始化、依赖安装、密钥生成、启动顺序与健康检查 |
| 2 | `basic-agent/app_factory.py` | Flask 装配与依赖注入 |
| 3 | `basic-agent/model_config.py` | 全局注册表、校验、原子写、临时 provider |
| 4 | `basic-agent/model_clients.py` | ChatOpenAI 构造、认证模式和缓存 |
| 5 | `basic-agent/openai_routes.py` | 模型列表、非流式与 SSE |
| 6 | `basic-agent/rag_utils.py` | LangGraph、FAISS、出题和判题 |
| 7 | `basic-agent/internal_routes.py` | 私有 provider 内部边界 |
| 8 | `basic-agent/exam_routes.py` | 整卷生成、判卷和模型锁定 |
| 9 | `basic-agent/exam_store.py` | 两小时/200 份线程安全缓存 |
| 10 | `open_webui/models/agent_model_providers.py` | 用户表、服务层、加密读写 |
| 11 | `open_webui/utils/agent_provider_security.py` | Fernet 与 SSRF 规则 |
| 12 | `open_webui/routers/agent_user_model_providers.py` | 用户 CRUD 与管理员治理 |
| 13 | `open_webui/routers/agent.py` | 同源代理、私有路由和 SSE 转发 |
| 14 | `open_webui/main.py` | `/api/models` 合并与主聊天分流 |
| 15 | `AgentUserModels.svelte` | Connections 中的私有模型 UI |
| 16 | `ExamPanel.svelte` | 整卷状态机、分页、恢复与结果 |
| 17 | `apis/agent-user-model-providers/index.ts` | 前端 API 类型与请求 |

阅读时先跟踪一次 `GET /api/models`，再跟踪一次 `POST /api/chat/completions`，最后阅读 RAG/quiz。这样能先建立路由心智模型，再进入 LangChain 细节。
