查出并修好 2 个问题：

| 问题 | 原因 | 修法 | 判据 |
|---|---|---|---|
| **整卷出不了卷**：「AI 输出结构异常」，两次重试都失败 | `extract_json` 在全文里找第一个 ``` 代码块：教材里有 C 代码，模型把 ```c ... ``` 写进了大题的参考答案（JSON 字符串里），取出来的是 `c\nvoid timing()…` | 本身就是 JSON 就原样解析；只剥**最外层**的代码块包装（贪婪到最后一个 ```）；夹了说明文字时取首个 { 到最后一个 } | 3 条新测试（字符串里带代码块、外层包装里再有代码块、前后夹说明文字）；改回旧实现两条变红。实测出卷 10 秒、21 道题 |
| 一个字都没回就点「停止」，问题下面空着、没有「重新生成」 | 停止时只把正在生成的消息收尾，没有消息可收 | 停止时最后一条是提问就补一条空的「没有完成」 | 浏览器实测：停止后出现提示与「重新生成」，点了正常答完、标记清掉 |

### 没能核对的
- 本机 OpenNotebook 里没有笔记本，「计算机网络」笔记数量这一项无法用真实数据核对。代码上看：OpenNotebook 的 `/api/notebooks` 本身就返回
  `note_count`，原来显示 0 是因为前端读的是没人填的 `noteCount` 字段；她的修法是对每个笔记本再取一遍全部笔记来数数，结果正确，
  但每次打开答疑页会多发「笔记本个数」那么多个请求、把笔记全文都拉回来。笔记本多的时候可以改成直接用 `note_count`——需要她确认两边的数一致。
