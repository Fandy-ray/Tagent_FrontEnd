# 升级轮次

一轮接一轮升级，**每一轮的计划都要保存**。每轮一个文件 `round-NN.md`，
开工时写下计划（要做什么、为什么、怎么验证），收口时补上结果（实测数字、扰动结果、留给以后的事）。

每一轮都包含一段「暴力测试」：连点、狂刷新、中途打断、断网 / 服务卡住、一个班同时用。
每一轮收尾前都要把全套检查再跑一遍（后端测试、类型检查、lint、构建、浏览器实测、压测），
有新问题就修、修完再查，直到一轮完整检查零新问题。

「扰动」：把每处修复临时改回去，跑对应的测试，必须变红 —— 证明测试真能拦住它回来。
